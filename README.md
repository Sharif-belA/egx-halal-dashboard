# 🕌 EGX Halal Trading & Analytics Dashboard
### منصة المتابعة والتحليل الفني للأسهم النقية بالبورصة المصرية

منصة ويب تفاعلية متكاملة لمتابعة وتحليل الأسهم المتوافقة مع الشريعة الإسلامية بنسبة تطهير 0.00% في البورصة المصرية (EGX).

---

## 🌟 مميزات المنصة:
- ⭐ **نظام المفضلة الدائم:** حفظ الأسهم المفضلة في المتصفح وعرضها ومتابعتها دائماً.
- 📈 **رسوم بيانية تفاعلية:** مخططات أسعار لحظية مع متوسطات الحركة EMA ومؤشر القوة النسبية RSI بفترات زمنية متعددة (1D, 1W, 1M, 6M, 1Y).
- 🔍 **فحص شامل للأسهم:** جدول تفاعلي للـ 18 سهماً النقية مع بحث سريع وفلترة حسب القطاعات والإشارات (شراء 🟢 / بيع 🔴 / احتفاظ ⚪).
- 🌅 **تقارير الصباح ونجم الجلسة:** توصيات افتتاح الجلسة الصباحية وأفضل سهم أداءً في ختام التداولات.
- 📱 **واجهة مستخدم عصرية:** متجاوبة 100% مع الهواتف الذكية وأجهزة الكمبيوتر مع دعم اللغة العربية RTL والوضع الليلي (Dark Theme).
